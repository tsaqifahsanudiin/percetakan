INSTALL:
1. Copy this folder to wp-content/themes/
2. WordPress Dashboard > Appearance > Themes > activate Percetakan.
3. Create pages with slugs: layanan, tentang-kami, panduan, kontak.
4. Settings > Reading > set homepage to a static page, or leave front page enabled for the custom front-page.php.
5. Visit the site.

NOTE: The design uses Tailwind CDN and remote Google-hosted images from the Stitch export.
